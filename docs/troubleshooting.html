Troubleshooting

Start over

On the checklist, open Instructions & backups, select Clear saved answers, and confirm. To clear one rating, choose Left blank for that topic.

Answers do not save

Allow this site to use browser storage. Use the same browser profile and site address when you return to the checklist.

Move or restore saved answers

Find the backup controls under Instructions & backups on the checklist or under Answer backup on the results page. Select Export backup to download a copy. In the browser where you want to restore your answers, select Import backup, choose the downloaded JSON file, and confirm. This replaces all saved answers in that browser, including answers left blank in the backup.

Read aloud is unavailable

Install an English speech voice through your device’s settings, then reload the page. The app uses voices that your browser identifies as local.

Image download fails

Try Download text on the results page or follow the iPhone and iPad download guide.
