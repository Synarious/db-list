Troubleshooting

Start over

On the checklist, open Menu → Instructions & backups, select Clear saved answers, and confirm. To clear one rating, choose Left blank for that topic.

Answers do not save

Allow this site to use browser storage. Use the same browser profile and site address when you return to the checklist.

Move or restore saved answers

Find the backup controls under Menu → Instructions & backups on the checklist or under Answer backup on the results page. Export a copy as JSON. To import it, choose Import backup, select the file, and confirm.

Import fills blank fields with compatible values and keeps existing answers and profile details. It skips changed or removed questions, duplicate ratings, and invalid values. Older backups rely on known question IDs, so entries with an ambiguous meaning are skipped.

Using a screen reader

Use your screen reader’s headings and form controls to navigate. With a keyboard, use Tab to reach Previous, Next, or the section picker at the bottom. Press Enter or Space to open the picker. Use the arrow keys to move between ratings for an option.

Image download fails

Try Download text on the results page or follow the iPhone and iPad download guide.
